# IOStuff Scenes

Bibliothèque des scènes IOStuff. Une scène est un firmware qui se compile avec [IOStuff_Nodes](https://github.com/isokar/IOStuff_Nodes). Ce dépôt ne contient pas le socle, ni un installeur, ni un mécanisme d'OTA.

Chaque scène a son dossier. Le sketch Arduino porte le nom de la scène.

| Scène | Id | État |
| --- | --- | --- |
| [Cathedral](Cathedral/cathedral_nodes) | `iostuff.cathedral` 0.1.0 | Référence, validée sur le module RGB |

Emplacements prévus, pas encore versionnés : Aquarium, Artemis, LightRoom.
